# Grounds for Defense (Phaser)

> **© 2026 Kanen Coffee, LLC. All Rights Reserved.**
> Proprietary software. See [LICENSE](./LICENSE) for terms.

A coffee-themed tower defense + quality-control teaching tool. Browser-based (Phaser 3, no build step).

**Play live:** https://kanencoffee.github.io/grounds-for-defense/

A separate Godot 4 port lives at:
https://github.com/kanencoffee/grounds-for-defense-godot

## Run locally

Just serve the directory with any static server:

```bash
python3 -m http.server 8765
```

Then open http://localhost:8765

## What's in it

- 7 inspection-tool defenses (each with a specialty: visual / aroma / date / taste)
- 6 coffee defects (Sir Stales-A-Lot, Grind Zero, Burny McBurnFace, Mr. Wishy-Washy, Skin-Deep Milk, Pod-zilla)
- 10 escalating waves
- Procedural Web Audio (no external sound files)
- Custom hand-authored SVG sprite set
